# Version

[🏠 Home](../../../README.md) / [CLI Documentation](../../../src/WhoAmI.CLI/README.md) / [Usage](../usage.md) / **Version**

---

## Description

Displays the CLI version.

---

## Synopsis

```shell
whoami-cli version [options]
```

Alias:

```shell
whoami-cli v [options]
```

---

## Options

| Options | Alias | Required |  Type   | Description            |
|:--------|:-----:|:--------:|:-------:|:-----------------------|
| --help  |  -h   |    No    | boolean | Displays command help. |

---

## Validation

Not applicable.

---

## Examples

### Minimal

Display the CLI version.

```shell
whoami-cli version
```

Expected output:

```text
WhoAmI CLI - v1.0.0
```

### Alias

Display the CLI version using the command alias.

```shell
whoami-cli v
```

Expected output:

```text
WhoAmI CLI - v1.0.0
```
